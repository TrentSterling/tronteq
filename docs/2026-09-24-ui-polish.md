# Visualizer browser polish, September 24, 2026

The VIZ sidebar now uses the same production-rendered thumbnail tiles as the
expanded gallery. Scene selection, active outlines, hover descriptions, keyboard
focus, and favorite stars have one implementation. Favoriting a tile keeps the
current scene playing and leaves the gallery open.

The browser reveals the current scene on entry or an external scene change,
uses the panel's available height, and switches to compact thumbnail rows when
there is too little height for a complete tile. Search, categories, favorites,
Next, Off, and Shuffle remain available. Empty search results offer Clear filters.
The atlas is decoded once and shared between the sidebar and expanded gallery.

Scene identity, view controls, and Scenes / Style / Effects / Meters navigation
stay above the scrolling controls. Style, Effects, and Meters keep independent
scroll positions. Header spacing is tighter; the footer's full EQ gesture guide
is now available by hovering EQ controls, leaving the meters easier to read.

The common controls, ordered effects, saved looks, transitions, and presentation
mode from the earlier visualizer passes are preserved. This change does not
change the audio installation or choose a different sound.
