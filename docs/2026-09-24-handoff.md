## Delivered UI

- One 37-scene visualizer library, shared controls, and an ordered effect stack.
- Thumbnail browsing, search, favorites, saved looks, transitions, render quality,
  clear Stage view, and fullscreen presentation.
- Compact layouts, fixed visualizer navigation, a simpler sound-profile toolbar,
  and a cleaner footer.
- Separate visual undo/redo for scene, look, style, and effect edits. A drag is
  one history entry; automatic scene cycling is not an edit. Ctrl+Z/Y follows
  the active inspector, and text fields keep their own undo. Visual history is
  session-only and does not restore sound, window settings, or the saved library.
- An Enable effects comparison switch preserves the full stack. Mixes display
  percentages; each effect has a description and a menu for moving up/down or
  removing it. All those art edits can be undone. Existing looks migrate with
  effects enabled; new looks retain the comparison switch.

Manual scene selections and history navigation restart the shuffle interval so
the chosen scene gets a full interval before the next automatic change.
