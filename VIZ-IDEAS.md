## Architecture notes for the next waves
- All shaders share the VizBus uniform block (bass/mid/treb/pulse/phase/bright + bpm/
  conf/flux/loud/crest/corr/width) + spec/wave/hist textures — new signals get added to
  FRAG_COMMON once and every mode inherits them.
- The FX overlay pass is ONE uber-shader with a bitmask — new overlay bits are cheap.
  Real bloom (128) needs a downsample/blur chain: separate follow-up.
- Painter modes (Bars XL etc) can't use FX bits yet — FX applies to the GL stage only.
  Compositing painter output through the GL pass = bigger refactor, queued.
- Curation plan: once the roster crosses ~40, add a favorites/hidden system so the
  chip grid shows only Trent's picks (plus Shuffle drawing from favorites only).
